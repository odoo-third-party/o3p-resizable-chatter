# O3P Resizable Chatter

Minimal resizable side chatter for Odoo 20.

Drag the chatter's left edge to resize it. The addon preserves Odoo's native
layout and changes only the existing `--Chatter-asideExtraWidth` CSS custom
property. The selected width is remembered in the current browser across pages
and sessions. Double-click the resize edge to forget it and restore Odoo's
default width.
